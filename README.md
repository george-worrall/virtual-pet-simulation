# Virtual Pet Simulation

A console-based virtual pet simulation developed in C# using object-oriented programming principles.

## Features
- Real-time stat updates
- Hunger, mood, boredom, and health systems
- Coin and inventory system
- Feeding, medicine, and toy interactions
- Automated simulation updates using timers

## Technologies Used
- C#
- Object-Oriented Programming
- Visual Studio Code

## Concepts Demonstrated
- Classes and objects
- Inheritance
- Encapsulation
- Timers and automated updates
- Inventory and state management

## Project Overview
The application simulates the management of a virtual pet through interactive gameplay systems and automated stat updates. The project focused on applying object-oriented programming concepts alongside game logic and state management systems.
